# Changelog

## [Unreleased]

### Fixed
- В репозитории не было `go.sum` — свежий клон не собирался (`go build`
  падал с «missing go.sum entry»). Сгенерирован через `go mod tidy`
- Общий глобальный inline-буфer для текста параграфов не разделялся по
  границам вложенных ссылок/emphasis/кода: при выходе из ВТОРОЙ ссылки
  в одном абзаце `flushInline()` захватывал уже отрендеренный ANSI-вывод
  ПЕРВОЙ ссылки и прогонял его через `Style.Render()` повторно — escape-
  коды дробились посимвольно, и любой абзац с двумя и более inline-стилями
  подряд рендерился в нечитаемый мусор. Заменено на стек областей: каждый
  вложенный спан теперь получает свой буфер и не трогает содержимое,
  накопленное до него
