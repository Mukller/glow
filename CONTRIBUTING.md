# Contributing

## Как помочь

Принимаю PR с:
- Новыми темами (добавить в `themes.go`)
- Поддержкой новых Markdown-элементов
- Исправлением рендеринга edge-кейсов
- Оптимизацией для широких терминалов

## Как делать

```bash
git clone https://github.com/Mukller/glow
cd glow
go mod tidy
go build .
```

Тестируйте на реальных `.md` файлах. Проверяйте в тёмном и светлом терминале.

## Стиль

- `gofmt` обязательно
- Без внешних зависимостей кроме goldmark и lipgloss
- Новые темы — только через `lipgloss.Style`, без хардкода цветов
